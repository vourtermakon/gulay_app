# Гуляй! — кликабельный прототип

AI-конструктор городских прогулок. Прототип для итоговой защиты проекта (ИТМО, «Основы продуктового подхода»).

**Ссылка:** https://vourtermakon.github.io/gulay_app/

Открывается в любом браузере, без регистрации и установки. На телефоне выглядит как приложение, на компьютере — в рамке телефона.

## Что можно пройти

1. **Описать прогулку → получить маршрут.** Экран «Куда пойдём?» → «Собрать маршрут» → 3 варианта → карточка маршрута.
2. **Карта и замена точки.** В маршруте «Маршрут на карте» → стрелки ‹ › листают точки → «Заменить». Можно выбрать похожее место, найти по поиску или отметить свою точку на карте.
3. **Гулять.** В маршруте «Гулять» → прогресс, погода, «Интересное по пути» → «Я на месте».
4. **Сохранить.** Закладка вверху маршрута → вкладка «Сохранённые» → открыть маршрут.

Сценарий компании подруг: на первом экране «Компания» → «Компания 3–5».

## Полезно знать

- Параметры, сохранённые маршруты, замены и прогресс прогулки хранятся в браузере (localStorage).
- Начать с чистого листа: добавьте `?reset` к ссылке — https://vourtermakon.github.io/gulay_app/?reset
- Места реальные (Санкт-Петербург). Часы работы, цены и вход заведений не проверены и помечены «Уточнить». Погода — пример.
- Карта — стилизованная схема, не реальная карта.
- Цена PRO — **299 руб.**/мес (в прототипе не показывается, только счётчик «1 из 2» бесплатных маршрутов).

## Мокапы

Мокапы снимаются с этого же `index.html`, поэтому совпадают с прототипом один в один:

```
pip install playwright && python3 -m playwright install chromium
python3 tools/render.py
```

Результат — папка `mockups/`: 7 PNG в рамке iPhone 15 с прозрачным фоном и `mockups/screens/` — экраны без рамки 1179×2556. Параметры кадров описаны в начале `tools/render.py`.
